# Prada Website Recreation

A frontend recreation of the Prada official website, built as a personal web development project. The project focuses on recreating a luxury fashion e-commerce experience through minimalist design, interactive product sections, and responsive layouts.

## Overview

This project is an independent frontend practice project inspired by Prada's website. It explores luxury website design, product presentation, navigation, and interactive user interfaces.

## Technologies Used

- HTML5
- Tailwind CSS 3
- JavaScript (ES6+)
- Vite
- Remix Icon

## Features

- Luxury-inspired minimalist interface
- Navigation menu
- New arrivals section
- Separate men's and women's product collections
- Interactive product switching
- Bags and shoes collections
- Fashion editorial and news sections
- Image and video assets

## Getting Started

To run this project locally:

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project folder:

```bash
cd tailwind3-project
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL provided by Vite in your browser.

## Production Build

To create a production build, run:

```bash
npm run build
```
